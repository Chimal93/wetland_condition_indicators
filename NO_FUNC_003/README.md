# NO_FUNC_003 — Functional Plant Community Index, Wetlands

Open-source, self-contained reconstruction of NINA's wetland functional
plant community indicator. Every input is either fetched from a public
source, manually downloaded from a public (but bot-blocked) source, or
independently reconstructed - no NINA-internal access is required to
run anything in this folder.

Developed under the documentation standard of NINA's
[ecRxiv](https://github.com/NINAnor/ecRxiv) publishing platform for
Ecosystem Condition indicators. This is an independent reconstruction and
not an official NINA product; it has not gone through ecRxiv's
publication workflow.

This is one indicator's subfolder within a larger multi-indicator repo
(5 indicators planned in total). Everything below is self-contained to
this folder - all scripts resolve paths relative to their own location,
not to the repo root.

## What this indicator measures

For each ANO (national field-monitoring) wetland plot, computes a
community-weighted mean of four plant trait indicators (Light,
Moisture, Soil reaction/pH, Nitrogen) from the species recorded there,
scales each against reference/limit values for that plot's NiN wetland
type, and takes the lowest-scoring indicator as the plot's condition
score ("worst-rule" / verste-styrer principle). Aggregated to national
and regional medians with bootstrap confidence intervals.

## Folder structure

| Folder | Contents |
|---|---|
| `Main/` | The pipeline (`NO_FUNC_003_wetland_pipeline_OpenSource.R`). |
| `Fetch/` | Scripts that download or build each input. Run these first. |
| `Data/` | `NINA/` = reused open reference data (shared across indicators, not independently fetch-scripted yet - see Known limitations). `OpenS_data/` = fetched/built inputs; the two large ones (ANO export, B12 dataset) are gitignored and regenerated by the Fetch scripts. |
| `Results/` | The pipeline's map and its final tables (index by region x period, supplementary indicators, plot-level values). |
| `Deliverables/` | The indicator in the ecosystemCondition platform format - region and plot maps (`.rds`, EPSG:25833), values table (csv/xlsx with metadata and supplementary sheets), figure. Produced by `Main/export_deliverables.R`. |

## How to run it (in order)

1. `Fetch/fetch_ano_data.R` - downloads the national ANO field-monitoring
   export (public, no login, ~60MB).
2. `Fetch/fetch_b12_data.R` - downloads Artsdatabanken's B12 species-list
   dataset (public, no login, ~51MB).
3. `Fetch/get_tyler_data.R` - **manual step**. Run it: if Tyler et al.
   (2021)'s indicator values are missing it prints exactly where to get
   them, and once present it verifies the `"Taxa"` sheet is there.

   The file is the publisher's supplementary material and is not
   redistributed here. Download it from the article
   ([doi:10.1016/j.ecolind.2020.106923](https://doi.org/10.1016/j.ecolind.2020.106923),
   under "Supplementary material"/"Appendix A") and save it as
   `Data/OpenS_data/Tyler_data_raw.xlsx`. ScienceDirect, ResearchGate
   and DOAJ all block scripted downloads, so this cannot be automated.

   > Tyler, T., Herbertsson, L., Olofsson, J., Olsson, P.A. (2021).
   > Ecological indicator and traits values for Swedish vascular plants.
   > *Ecological Indicators*, 120, 106923.
4. `Fetch/build_wet_ref_openS.R` - builds the bootstrapped reference
   table from steps 2-3 (~1 min, mostly a 1000-iteration bootstrap).
5. `Main/NO_FUNC_003_wetland_pipeline_OpenSource.R` - the actual
   indicator computation. Produces the map in `Results/`, prints the
   national/regional index tables and (Stage 11) writes them to
   `Results/`: the index by region and period, the eight underlying
   indicators, the round breakdown, and one row per ANO plot visit
   (`NO_FUNC_003_plots.gpkg` / `.csv`).
6. `Main/export_deliverables.R` - writes the finished indicator in the
   ecosystemCondition platform format to `Deliverables/` (see
   "Deliverables" below). Seconds; reads `Results/` only.

Each script has a 3-tier working-directory fallback and runs the same
way from RStudio, `Rscript script.R`, or `source("script.R")`.

### Quick test, without the full run

Once step 1 (ANO fetch) has been done at least once, `Fetch/
quick_test_small_aoi.R` runs the *real, unmodified* Main script against
one small region (default Nord-Norge) instead of the whole country -
useful to confirm your setup actually works in well under a minute,
without waiting on the full multi-minute national run. It temporarily
swaps in a small-region subset of the ANO data, runs Main as a genuine
separate process, and restores the real data and real map afterward -
Main itself is never modified and has no awareness this exists. Output:
`Results/NO_FUNC_003_wetland_map_2019to2021_TEST_AOI.png` (gitignored -
not a real result, just a smoke-test artifact). Set `FUNC003_TEST_REGION`
to test a different region (Nord-Norge, Midt-Norge, Vestlandet,
Østlandet, Sørlandet).

## Deliverables (platform format)

`Main/export_deliverables.R` maps the results onto the ecosystemCondition
platform schema (`area, areaId, v_YYYY, sd_YYYY, i_YYYY, reference_high,
reference_low, thr`; see the repository README). Points specific to this
indicator:

- Two file sets:
  - `NO_FUNC_003_*` - the original indicator's two 3-year periods, every
    survey in those years: `_2021` (ANO 2019-2021) and `_2024` (ANO
    2022-2024).
  - `NO_FUNC_003_cycle1_2019to2024_*` - one full ANO monitoring cycle,
    using each plot point's **first** survey only, so no point is counted
    twice: `_2024` (ANO 2019-2024).
- ANO revisits each point on a 5-year rotation. Visits are numbered per
  plot point (`ano_visit` in `Results/NO_FUNC_003_plots.*`). When the
  export covers the whole second rotation, set `include_cycle2 <- TRUE`
  (and `cycle2_last_year`) in Stage 10 of the pipeline; the cycle-2
  tables, map and `NO_FUNC_003_cycle2_*` deliverables then follow
  automatically. Off by default: only ~180 wetland points had been
  revisited in the 2019-2024 export.
- `v = i`: the index is a worst-rule minimum over eight scaled indicators
  and has no single unscaled variable (the platform's own Nature Index
  example does the same). The four raw community-weighted means and the
  eight scaled indicators are in the workbook's `supp_*` sheets.
- `thr = 0.6` is a genuine X60 here: the reference distribution's
  0.25/0.75 quantile is mapped to 0.6 by the scaling function.
- `sd` = bootstrap standard deviation of the median over plot visits; the
  pipeline's 95 % bootstrap CI is kept as `boot_low`/`boot_high`.
- Units: landsdel (primary) and every scored ANO wetland plot point
  (`areaId` = `ano_punkt_id`).

### The four vegetation indicators as separate indicators

The light, moisture, pH and nitrogen indicators are also delivered as
separate indicators, following NINA's split functional plant indicators
on ecRxiv (NO_FULI_002, NO_FUMO_004, NO_FUNI_002/004, accepted 2026):

| ID (provisional) | Indicator | Scaling |
|---|---|---|
| `NO_FULI_003` | Vegetasjonsindikator for lys | two-sided, limits = 0.025 / 0.975 quantiles |
| `NO_FUMO_003` | Vegetasjonsindikator for fuktighet | two-sided, limits = 0.025 / 0.975 quantiles |
| `NO_FUPH_003` | Vegetasjonsindikator for pH | two-sided, limits = 0.025 / 0.975 quantiles |
| `NO_FUNI_003` | Vegetasjonsindikator for nitrogen | one-sided (enrichment only), limit = 0.95 quantile |

- Each plot is scaled per side (scale end -> 0, limit -> 0.6, reference
  median -> 1, truncated), and a two-sided indicator is the product of its
  two sides, as in NINA's code. The scaling function reproduces
  `ec_normalise()` from **current** eaTools: the eaTools version pinned in
  this repository (needed by NO_GJEN_001/002) has a bug in the decreasing
  direction that NINA fixed in May 2026 (eaTools commit `ca7bc797`).
- National and regional values come from NINA's model: an ordered beta
  regression (`glmmTMB`, family `ordbeta`) with ANO site as a random effect.
  `i` = model mean, `sd` = SD of 1000 draws, `ci_low` / `ci_high` = 95 %
  interval; `mean_lower` / `mean_upper` with `n_lower` / `n_upper` show the
  direction of the deviations.
- File sets `<ID>_*` (3-year periods) and `<ID>_cycle1_2019to2024_*`
  (first survey per point), as for the combined index. Results table:
  `Results/NO_FUNC_003_factor_indicators.csv`.
- Kept from this reconstruction: reference values per NiN main type
  (V1/V2/V3) from Artsdatabanken's B12 lists, not per mapping unit. pH has
  no NINA counterpart; it is included because it was selected for wetland.
- The combined index `NO_FUNC_003` (worst-rule over the eight sides,
  0.25 / 0.75 limits, median aggregation) is unchanged and kept as a
  supplementary product.
- Report maps for the four indicators (ANO cycle 1, same style as the
  other wetland indicators): `Main/make_factor_report_maps.R` ->
  `Results/<ID>_wetland_map_report.png`.
- Needs the R package `glmmTMB` (CRAN).

## Known limitations

- **V4 (Kilde) and V8 (Strandsumpskogsmark) wetland types are not
  independently reconstructed** - together 0.88% of real ANO wetland
  plots (27 of 3,083). No public species list exists for V8; V4's
  candidate source (Artsdatabanken's B04) was set aside as too fragile
  to untangle, not confirmed impossible. Plots of these two types are
  excluded from scoring rather than patched from a gated source -
  confirmed empirically to shift the final index by under 0.003,
  smaller than its own bootstrap confidence interval. **Not treated as
  permanently closed** - see `build_wet_ref_openS.R`'s header for how
  to extend it if a new or reworked public source ever appears.
- **`Data/NINA/spatial/regions.shp`** is the five-region delineation from
  [NINAnor/ecosystemCondition](https://github.com/NINAnor/ecosystemCondition)
  (`data/regions.shp`), redistributed here under its CC BY 4.0 license.
  Note its `region` column has a character-encoding fault for Østlandet
  and Sørlandet, so this pipeline reassigns those two by `id` rather than
  reading the string - do not "fix" that by trusting the column.
  `outlineOfNorway_EPSG25833.shp` is reused from the same project but its
  origin has not been separately confirmed; it affects only map rendering,
  never a computed value.
- Deviations from NINA's original methodology are summarised in the
  Known limitations above and in `Main`'s stage headers.
